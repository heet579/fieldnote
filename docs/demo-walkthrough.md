# Explorer walkthrough

1. Open the explorer. The default shows the whole June 2015–September 2018 archive.
2. Choose temperature, conductivity or dissolved oxygen. Read the short measurement explanation.
3. Select a year; note that 2015 and 2018 are partial archive years.
4. Switch on location comparison or choose a single monitoring spot.
5. Expand the monthly table to inspect counts, averages and original-reading extremes.
6. Download the selected view, or obtain all daily summaries from About the data.
7. Read the source attribution, time-basis limitations and missing-data explanation.

For technical review, inspect source/member hashes, the exact source-to-fact comparison, load reconciliation and separate restore verification. Synthetic tests are kept separate from genuine observations.
